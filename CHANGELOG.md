# Changelog

## v0.2.1

- preserved the complete frozen v0.2 result set and default mechanics;
- corrected the old `E_ablate_plural_control` interpretation: the frozen ablation removes redundancy while control remains independent;
- added a corrected v0.2.1 ablation catalogue with separate redundancy and control-independence ablations;
- added a structural-possibility audit for the held-route metric;
- added specification tests pinning down which C2/E and D/E contrasts hold by construction;
- added paired bootstrap intervals for the primary run and paired differences;
- lifted cognitive, institutional and scenario-generation literals into `ExperimentConfig` without changing defaults;
- added optional advocate-error correlation with a default of zero;
- added a mechanism decomposition and pre-specified cognitive-parameter sensitivity thresholds, including invalid-claim rejection reversals;
- corrected the description of strategic escalation to a conditional stipulated best response;
- prepared the compact public research repository under the `claimant-standing-sim` identity.

## v0.2

- added conditional strategic escalation where the claimant route stops at a jurisdiction boundary;
- replaced one-at-a-time attack categories with attack budgets and compound attacks;
- added shared-provider dependencies across evidence, advocacy, review and enforcement;
- added dynamic institutional cut-set calculation;
- added C2, a component-count-matched protected appeal under common control;
- added recognition, durability and tempo protection to the explicit standing model;
- added nine one-component ablations of the full E architecture;
- replaced truth-centred reviewer coin flips with noisy observations of the policy margin;
- added correlated reviewer error;
- added parameter sweeps and a dependency × attack grid;
- added a reach-effect decomposition;
- expanded tests from 9 in v0.1 to 14 in v0.2.

Initial CPU-only mechanism study with five conditions, single attacks, exogenous escalation and a static route-cut diagnostic.
