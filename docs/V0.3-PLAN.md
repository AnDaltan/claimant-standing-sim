# v0.3: model-mediated representation and review

## Purpose

v0.3 freezes the v0.2 institutional layer and tests whether protected claimant pathways remain substantively usable when representation and review are performed by fallible language models.

The central question is:

> When claimant standing is formally protected, do model-based advocates and reviewers preserve and act on the claimant's actual claim, and how do institutional independence and model/epistemic independence interact?

## Build sequence

The programme is staged so representation and review can be measured separately before integration.

### v0.3-R: representation

Replace the scripted advocate. A structured `ClaimSpec` is rendered as a claimant statement. A model advocate carries that claim into the higher-capability forum while preserving its polarity, target, qualifications and requested remedy.

Primary representation measures:

- essential proposition recall;
- polarity preservation;
- qualification preservation;
- remedy preservation;
- unsupported additions;
- explicit non-claim violations;
- proxy/claim substitution;
- parse success.

Claimant propositions and advocate analysis are stored in separate fields so substitution is directly observable. Matched cases also distinguish a claimant-authored objection from a guardian-inferred welfare signal.

### v0.3-J: review

After the representation instrument is calibrated, replace the v0.2 noisy-margin reviewer. Reviewers receive a bounded documentary case file and return structured findings. Canonical claimant representations are used first so review error can be separated from advocacy error.

Objective/adjudicable cases retain hidden structured scoring. Framework-challenge cases use procedural measures: whether the reviewer recognises the type of challenge, addresses the claimant's actual proposition and applies the available institutional response.

### v0.3-I: integrated experiment

After representation and review work separately, model advocates and reviewers are connected end-to-end.

## Experimental centre: two kinds of independence

The primary factorial separates institutional control from model/epistemic diversity:

| | Model monoculture | Heterogeneous model families |
|---|---|---|
| Common institutional control (C2) | C2-M | C2-H |
| Plural institutional control (E) | E-M | E-H |

This separates four questions:

- whether institutional plurality helps when cognition is homogeneous;
- whether model diversity helps under common institutional control;
- how often heterogeneous models fail together;
- how political/control independence and epistemic independence interact.

Independence is measured empirically through pairwise failure correlation, conditional co-failure and error-category overlap. C remains the single protected-route control and D retains the reach ablation.

## Data discipline

All model calls are content-addressed and cached using the case, role, prompt version, model/revision, visible evidence, generation parameters and seed. Where two institutional conditions expose a cognitive role to exactly the same material, the same cached model response is replayed into both conditions.

This preserves the paired-comparison discipline of v0.2 and removes generation luck from the institutional comparison.

## Initial case bank

A planned evaluation bank contains structured cases from six families:

1. factual emergency error;
2. jurisdictional overreach;
3. withheld/conflicting evidence;
4. representation/proxy dispute;
5. escalation/reach dispute;
6. framework/constituent challenge.

Development cases are kept separate from the frozen evaluation bank. Case text is rendered deterministically from structured specifications.

## Pre-specified discriminating outcomes

The implementation direction is weakened if:

- advocates frequently substitute their own or institutional claims despite adequate task competence;
- plural advocacy obscures or increases representational distortion;
- structural route availability survives while semantic claim fidelity collapses;
- different model families exhibit strongly correlated errors on the same cases;
- a single competent protected reviewer matches plural review under the relevant stresses;
- common institutional control and plural control perform similarly under the relevant attacks;
- the reach effect disappears under model-mediated review;
- operational latency/cost makes protected review impractical;
- findings depend strongly on one prompt wording or output schema.

Each is retained as a reported outcome.

## CPU-derived v0.3 calibration targets

v0.2.1 supplies two especially useful reviewer thresholds for E versus C on invalid-claim rejection:

| Parameter | v0.2 default | Sign change | Significant reversal |
|---|---:|---:|---:|
| Reviewer error correlation | 0.25 | 0.30 | 0.75 |
| Good-condition reviewer noise | 0.18 | 0.20 | 0.40 |

v0.3 measures reviewer error and co-failure directly. The CPU parameter is the correlation of a hidden Gaussian error term, and observed co-failure also reflects shared case difficulty, so a conversion from the CPU model to observable co-failure rates is computed and frozen before any model observation is compared with these thresholds.

## Compute scope

The first representation pilot uses one local or API model, a development case bank and a few hundred cached generations. The multi-family study follows after the representation and review instruments discriminate their target failures reliably. This keeps compute tied to explicit experimental stages and preserves cached outputs for replay across institutional conditions.
