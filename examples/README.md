# Episode sample

`episode_sample.csv` contains all six institutional-condition rows for **20 shared scenarios** selected deterministically from the frozen 20,000-scenario primary ledger.

The sample is provided for inspection only. It is deliberately not a statistical sample and must not be used to recompute the headline results. Selection covers ordinary cases and several stress classes, including escalation, strategic escalation, compound attack, high shared dependency, high capability gap, fast/irreversible execution, valid and invalid claims, and cases where C2/E or D/E diverge.

The complete primary and ablation episode ledgers are retained in the private frozen v0.2 provenance artefact described in `release/FULL-ARTIFACT.md`.
